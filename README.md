# Інтертехкорм

Односторінковий сайт компанії «Інтертехкорм» із каталогом кормових білкових інгредієнтів ACTIPRO Plasma та ACTIPRO Hemoglobin.

## Локальний запуск

Відкрийте `index.html` у браузері. Для розробки також можна запустити будь-який локальний HTTP-сервер у корені проєкту.

## Публікація на GitHub Pages

Сайт не потребує збірки: GitHub Pages має публікувати корінь репозиторію. Перед фінальною публікацією потрібно:

1. перевірити адресу сайту в `canonical`, Open Graph, `robots.txt` і `sitemap.xml`;
2. за потреби заповнити `FORM_ENDPOINT` в `index.html` (поки він порожній, форма відкриває поштову програму);
3. перевірити `robots.txt` і `sitemap.xml` за кінцевою URL-адресою сайту.
